# С чего начать

Это рабочий локальный анализатор логов для задач первой линии SOC: импорт, нормализация, восемь детекторов, кейсы, доказательства, приоритет, заметки и отчёты. Программа работает без внешних сервисов.

## Запуск

Из каталога проекта, с Python 3.12/3.13 и установленным `uv`:

```sh
uv sync --locked --group dev
uv run lia demo --output reports/my-demo
```

Открыть `reports/my-demo/report.html`. Для каждого запуска указывать новый выходной каталог.

В текущей рабочей папке уже настроено Python-окружение. В PowerShell демо можно запустить напрямую:

```powershell
.\.venv\Scripts\lia.exe demo --output reports/my-demo
```

В скачиваемый архив окружение `.venv` не входит; после распаковки используется установка через `uv` выше.

## Статус

Код, тесты, датасеты, Dockerfile и GitHub Actions находятся в проекте. Проверки Windows и двух версий Python выполнены. Linux, контейнер и абсолютный лимит времени на фиксированном Linux-стенде требуют отдельного запуска; они не отмечены как пройденные. Поэтому версия пакета — 0.1.0.

Git-репозиторий создан локально. Проект ещё не отправлен на GitHub. Перед публикацией изучить `docs/VALIDATION.md`; временные базы, ключи и большие рабочие данные исключены из архива и `.gitignore`.
